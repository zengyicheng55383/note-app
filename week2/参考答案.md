// 渲染：把数组变成页面
function render() {
  const main = document.querySelector(".note-list");

  main.innerHTML = "";

  notes.forEach((note) => {
    main.innerHTML += `
      <article class="note-card">
        <div class="note-meta">
          <span class="tag">${note.tag}</span>
          <time>${note.date}</time>
        </div>
        <h2 class="note-title">${note.title}</h2>
        <p class="note-excerpt">${note.excerpt}</p>
      </article>
    `;
  });
}

// 页面打开先画一次
render();

const btn = document.querySelector(".btn-new");

    date: "刚刚",
    title: title,
    excerpt: "（还没有内容）",

  render();
});

## 逐段解释

### 1. 为什么 `main.innerHTML = ""` 这句不能少

`render()` 的做法是「清空 → 重画」。如果不清空，每次调用都会往后面**追加**一遍，变成 8 张、12 张。

这也是「重新渲染」这个思路的核心：**它不修补页面，它是整个重画一遍**。听起来浪费，但代码简单、不容易出错，几乎所有前端框架都是这么干的。

### 2. 为什么用 `forEach`

`notes` 是数组，`forEach` 让我们对每个元素做同一件事。这里做的是：拼一段 HTML，加到 `main` 里。

### 3. 反引号 `` ` `` 和 `${}` 是什么

这叫**模板字符串**，是 JavaScript 拼字符串最方便的写法：

```js
const name = "张三";
console.log("你好，" + name);      // 老写法
console.log(`你好，${name}`);      // 模板字符串
```

反引号里面可以换行，所以能直接写多行 HTML，不用一行行拼。

### 4. 为什么是 `+=` 而不是 `=`

- `main.innerHTML = "..."` → **覆盖**，只剩最后一张卡片
- `main.innerHTML += "..."` → **追加**，四张都在

### 5. `if (!title) return;` 在防什么

`prompt()` 在用户点「取消」时返回 `null`，点「确定」但没输入时返回空字符串 `""`。两种情况都不该加空卡片。

`!title` 对 `null` 和 `""` 都成立，所以这一句把两种都挡住了。

### 6. 为什么新卡片的 `id` 用 `Date.now()`

`Date.now()` 返回当前毫秒时间戳，比如 `1731672000000`。它几乎不可能和已有的 id 重复，是随手生成唯一 id 最省事的办法。
